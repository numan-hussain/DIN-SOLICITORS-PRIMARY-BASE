# DIN Activities Workflow

Use `DIN-ACTIVITIES/` for day-to-day activity files, exports, working documents, generated resources and task outputs.

## Main Rule

Every activity must have its own folder inside:

`DIN-ACTIVITIES/`

Do not place loose working files directly in the main base folder.

## Folder Naming

Use this format:

`YYYY-MM-DD_activity-name`

Examples:

- `2026-04-27_meta-ads-copy`
- `2026-04-27_homepage-section-code`
- `2026-04-27_housing-disrepair-blog`
- `2026-04-27_director-message-draft`

## Standard Activity Folder Structure

Use only the folders that are needed.

```text
activity-name/
  00_BRIEF/
  01_RESOURCES/
  02_DRAFTS/
  03_EXPORTS/
  04_FINAL/
  05_NOTES/
```

## Folder Use

- `00_BRIEF/` - what the task is, goal, audience and requirements.
- `01_RESOURCES/` - files, images, notes, links, screenshots or references added by Numan.
- `02_DRAFTS/` - working versions.
- `03_EXPORTS/` - exported files, generated files or files to share.
- `04_FINAL/` - approved final version.
- `05_NOTES/` - decisions, checks and reminders.

## Export Rule

When exporting or creating any file for an activity:

1. Create an activity folder inside `DIN-ACTIVITIES/`.
2. Put source resources in `01_RESOURCES/`.
3. Put working drafts in `02_DRAFTS/`.
4. Put exported files in `03_EXPORTS/`.
5. Put final approved files in `04_FINAL/`.

## Resource Rule

If Numan needs to add files, ask him to place them inside:

`DIN-ACTIVITIES/YYYY-MM-DD_activity-name/01_RESOURCES/`

Then use those resources from that folder.

## Compliance Check

Before finalising any activity:

- Use British English.
- Follow Din Solicitors brand rules.
- Avoid misleading legal marketing claims.
- Do not include sensitive client information.
- Keep SRA and CAP Code compliance in mind.
- Save final files inside the correct activity folder.
