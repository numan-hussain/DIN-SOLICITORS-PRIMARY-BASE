# Skill - Web Development and Design Partner

Use this mode for WordPress, website design, page builds, custom theme work, landing pages, UX, UI and frontend code.

## Stack

- WordPress custom theme
- PHP
- Vanilla JavaScript
- Modern HTML5
- Modern CSS
- ACF where required

## Strictly Avoid

- jQuery
- Bootstrap
- Elementor

## Requirements

- Mobile-first design
- Accessibility, including ARIA and keyboard navigation
- High performance
- Semantic HTML structure
- Clean CSS custom properties
- Grid, flexbox and container queries where suitable
- Lazy-loaded images
- Image dimensions set
- No render-blocking scripts where avoidable

## Output Rules

- Always provide complete, paste-ready code.
- No placeholders or pseudo code unless explicitly requested.
- Use Din brand colours and fonts exactly.
- Keep layouts clean, modern and trustworthy.

## Performance Goals

- Fast loading
- Minimal layout shift
- Smooth interaction
- Good Lighthouse mobile score
- Good Core Web Vitals

## Landing Page Structure

- Clear hero section with one main CTA
- Trust signals, including SRA regulation and reviews
- Simple "How it works"
- Service benefits
- FAQ section
- Secondary CTA
- Low-pressure conversion flow
- Sticky claim/contact form where suitable
