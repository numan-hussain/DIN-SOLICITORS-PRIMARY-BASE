# Din Solicitors Primary Base

This is the main working folder for Din Solicitors projects.

Use this folder as the central base for:

- Website rebuilds and updates
- Marketing campaigns
- SEO and content planning
- Social media assets
- Paid advertising work
- Brand assets
- Reports
- Reusable templates
- Internal instructions and working skills

## Folder Map

- `00_INSTRUCTIONS/` - master operating instructions, compliance rules and brand guidance.
- `01_SKILLS/` - reusable working modes for marketing, web development, communication and creative work.
- `02_PROJECTS/` - one folder per project, campaign, rebuild or major workstream.
- `03_BRAND-ASSETS/` - logos, colour references, fonts, image direction and creative guidance.
- `04_WEBSITE/` - website structure, page plans, code notes and WordPress work.
- `05_CAMPAIGNS/` - campaign plans, ad concepts, creative testing and platform notes.
- `06_CONTENT/` - blogs, news, service-page drafts, FAQs and editorial planning.
- `07_REPORTS/` - marketing reports, SEO reports, ad performance and monthly reviews.
- `08_TEMPLATES/` - reusable briefs, page templates, ad templates and message templates.
- `09_ARCHIVE/` - completed, paused or old work.

## Working Rule

Create a new folder inside `02_PROJECTS/` for each new project.

Suggested naming format:

`YYYY-MM-DD_project-name`

Example:

`2026-04-27_website-new-version`
